# Auto Parts Inventory System

> A comprehensive web application for managing auto spare parts, tracking stock levels, and generating customized reports.

## About The Project
This system is designed to streamline the management of auto parts businesses. It provides a complete solution to display available parts, track inventory in real-time using unique part numbers (IDs), and extract valuable business insights through a dynamic reporting system with advanced filtering capabilities.

## Built With
* **Backend:** Java 17, Spring Boot
* **Database:** Microsoft SQL Server
* **ORM:** Spring Data JPA
* **Frontend:** Thymeleaf, HTML, CSS, JavaScript
* **Build Tool:** Maven

## Key Features
* **Inventory Tracking:** Monitor real-time stock levels and manage items easily using unique identification numbers for each spare part.
* **Parts Catalog:** A user-friendly interface to display and browse all available auto parts clearly.
* **Advanced Reporting:** Generate detailed, dynamic reports with comprehensive filtering options to analyze inventory data based on specific needs.
